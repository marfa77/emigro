## Прямой ответ

Сербия в 2026 — **транзитный хаб**, а не EU-коридор: быстрый въезд, легализация через бизнес/работу/семью/недвижимость, время на EU-пакет и относительно низкая стоимость жизни. Безвиз для граждан РФ — **30 дней**, не 90. Если горизонт больше месяца — сразу готовьте основание для ВНЖ.

Рабочие оси:

| Ось | Суть |
|-----|------|
| **Въезд** | Безвиз **30 дней**; White Card (пријава) ASAP |
| **ВНЖ** | DOO / ИП / Unified Permit / недвижимость / семья; закон — до **3 лет** |
| **Налоги** | CIT **15%**; ИП-паушал — **фикс** по решению ПУРС; IP Box у DOO ≈ **3%** на qualifying IP |
| **ПМЖ** | После **3 лет** непрерывного temporary residence |
| **Гражданство** | Ещё ~**3 года** на ПМЖ + языковое интервью / процедура отказа |
| **EU** | Хаб для консульств и документов; сербский ВНЖ ≠ Шенген |

Если цель — программа в ЕС, начните с [Emigro wizard](/ru/wizard). Хаб: [/ru/serbia](/ru/serbia).

## 1. Въезд и первые дни

### Безвизовый режим

| Параметр | Факт |
|----------|------|
| Срок безвиза | **30 дней** для граждан РФ (не 90) |
| Продление | Нет автоматического продления «туристического» срока |
| Визараны | Выезд и возврат **не обнуляют** лимит формально; на практике пограничники ведут учёт; схема рискованна |
| Регистрация адреса (White Card / пријава боравка) | Обязательна **вскоре после заселения** (часто ориентир **24 часа**) — через полицию / хозяина / онлайн-каналы. Без пријавы сложно открыть бизнес и подать на ВНЖ |
| 90 дней | Возможны при **отдельном основании** (виза C или действующая виза Шенгена / UK / US — другой правовой механизм, не «расширенный штамп») |

**Критично:** 30 дней — короткий срок. Если планируете оставаться, готовьте основание для ВНЖ сразу, а не «поживём — посмотрим». Перед поездкой сверяйте правила на [mup.gov.rs](https://www.mup.gov.rs/) и у авиакомпании.

### Чек-лист первых 7 дней

1. **День 1:** въезд, местная SIM (Yettel, A1, Telekom Srbija), заселение  
2. **День 1–2:** White Card / пријава — хозяин или лично в полиции  
3. **День 2–3:** налоговый номер (**PIB**) — через налоговую / ePorezi (для бизнеса)  
4. **День 3–5:** банк (см. раздел «Банки») — часто проще с пријавой / после подачи на ВНЖ  
5. **День 5–7:** юрист/бухгалтер по маршруту ВНЖ (ИП vs DOO vs работа)

## 2. ВНЖ: рабочие маршруты

С реформы 2023–2024 (применение с 2024) temporary residence можно выдать **до 3 лет** за раз (не дольше срока паспорта). На практике при первой выдаче по бизнесу/ИП МУП часто ставит **6–12 месяцев**; **3 года** чаще при семейных основаниях. Продление — при активном основании, налогах, взносах и действующей пријаве.

### 2.1. Через бизнес — DOO (ООО)

Популярный маршрут для предпринимателей и части фрилансеров с оборотом выше паушала.

| Параметр | Детали |
|----------|--------|
| Форма | DOO (*Društvo sa ograničenom odgovornošću*) |
| Минимальный капитал | **RSD 100** (~€1) |
| Директор | Может быть нерезидент; местный директор не обязателен по умолчанию |
| Регистрация | Обычно **5–14** рабочих дней через [APR](https://www.apr.gov.rs/) |
| Удалённая регистрация | Часто через доверенность |
| Основание для ВНЖ | Регистрация DOO + **proof of real activity** |

**Важно:** «пустой» DOO без оборотов/договоров плохо проходит. MUP проверяет **substance**: договоры, обороты, налоговые платежи. Стоимость setup с юристом — ориентир **€500–1 500** самостоятельно / **€2 000–4 000** с полным сопровождением (практика агентств, не госпошлина APR).

### 2.2. Через бизнес — ИП (preduzetnik) и паушал

Классический маршрут россиян с удалённым доходом до лимита паушала.

| Параметр | Детали |
|----------|--------|
| Регистрация | APR, часто **1–3** рабочих дня |
| Паушал | Фиксированные ежемесячные/квартальные платежи по **решению ПУРС** (код деятельности + муниципалитет), не процент от фактического оборота |
| Типичная нагрузка IT/фриланс | Ориентир **~200–250 €/мес** (налог + ПИО + РФЗО) — индивидуально |
| Лимит паушала | **6 млн RSD/год** (~€51 000) — при превышении переход на учёт по фактическому доходу |
| НДС (PDV) | Отдельный порог **8 млн RSD** (~€68 000) за 365 дней — обязательная регистрация; паушалец обычно **не** в системе НДС |

Типичные коды: 62.01, 62.02, 70.22, 73.11, 74.10 — выбирайте с бухгалтером.

**Не путать:** в паушале ставка **10%** применяется к **вменённой базе** из решения налоговой, а не к вашему обороту «€3 000 × 10%». Формула «10% от оборота» в рекламных обзорах — упрощение и часто ошибка.

### 2.3. Через работу (Unified Permit)

С 2024 — единый документ (residence + work). Работодатель / процесс подаёт пакет вместо раздельных ведомств.

| Параметр | Детали |
|----------|--------|
| Labor market test | Обычно нужен (публикация на Worknet, ориентир **~10 дней**) |
| Исключения | Высокие зарплаты, часть IT, статус International Company — case-by-case |
| Срок рассмотрения | Ориентир **30–60** дней |
| Proof of means | Для employment-based часто не требуется (после реформы) — сверяйте на дату подачи |

### 2.4. Через недвижимость

| Параметр | Детали |
|----------|--------|
| Минимальная стоимость | **Нет** официального порога в законе |
| Требование | Жилая недвижимость, пригодная для проживания |
| Срок ВНЖ | До 3 лет при сохранении основания |
| Практика | Квартиры от **€50k–70k** в Белграде часто проходят; земля / коммерция — сложнее |

Покупка ≠ гарантия ВНЖ. MUP оценивает adequacy. Не рассчитывайте на «купить студию и забыть».

### 2.5. Через семью

Супруг/дети гражданина Сербии или держателя ВНЖ — family reunification. С реформы для ближайших родственников граждан Сербии часть требований к means ослаблена — проверяйте актуальный список на MUP.

### Документы для ВНЖ через DOO / ИП (ориентир)

- Паспорт (запас срока — ориентир **≥3 месяца** после планируемого ВНЖ; на практике часто просят больше)  
- White Card / пријава + договор аренды  
- Решение APR (DOO или ИП) + PIB  
- Договоры / proof of activity + банковские выписки  
- Медстраховка (покрытие по требованиям MUP; ориентир €30 000+)  
- Справка о несудимости (апостиль + перевод на сербский)  
- Медсправка в Сербии (~30–50 €)  
- Фото 3,5×4,5  
- Квитанция пошлины (сумма меняется — сверяйте в MUP; ориентир десятки € / тысячи RSD)

**Срок рассмотрения:** закон/практика **30–90** дней. Итого от въезда до карточки — часто **2–4 месяца**, если справка из РФ уже в пути.

## 3. Налоги: DOO, ИП, IP Box, СИДН

### 3.1. DOO

| Налог | Ставка 2026 (ориентир) |
|-------|------------------------|
| CIT (налог на прибыль) | **15%** flat |
| Дивиденды (withholding) | **20%** (снижается по СИДН — часто до **5–10%** при правильном оформлении) |
| НДС standard / reduced | **20%** / **10%** |
| Порог НДС | **RSD 8 000 000**/365 дней (~€68 000) |

**IP Box (для IT-продуктов / copyright / патентов):**

- До **80%** qualified IP-дохода исключается из базы CIT  
- Effective rate ≈ **3%** на qualifying IP-доход (не на весь оборот компании)  
- Нужны: deposit/регистрация прав, R&D/substance в Сербии, учёт qualified expenses  

**R&D:** double deduction (до **200%**) расходов на R&D; отдельно — investment tax credit для стартапов (лимиты меняются — с бухгалтером).

### 3.2. ИП-паушал (не «10% оборота»)

| Параметр | Детали |
|----------|--------|
| Лимит оборота | До **RSD 6 000 000**/календарный год (~€51 000) |
| Как платите | **Фикс** по решению ПУРС: налог 10% + взносы на **вменённую базу** |
| Бухгалтерия | Упрощённая (KPO и т.п.), без полного учёта расходов |
| НДС | Паушалец, как правило, **вне** системы НДС |
| Выше лимита | Переход на bookkeeping / самоопорезивање по фактическому доходу или DOO |

Бухгалтерское сопровождение паушала — ориентир **50–100 €/мес**.

### 3.3. СИДН Россия–Сербия

Соглашение об избежании двойного налогообложения **действует** — важное отличие от Грузии (где СИДН с РФ не ратифицирован).

| Сценарий | Налоговый исход (упрощённо) |
|----------|------------------------------|
| Remote income, налоговый резидент Сербии | Налоги в RS (CIT/ИП); в РФ — зачёт/освобождение по правилам СИДН и статусу резидентства |
| Дивиденды DOO → РФ | Withholding в RS (база 20%, по СИДН часто ниже) |
| Зарплата от сербского работодателя | Удержание у источника в RS |

**Налоговое резидентство:** ориентир **183+ дня** или центр жизненных интересов. После резидентства Сербии — обязательства по правилам RS на мировой доход (с оговорками договора). Выход из налогового резидентства РФ **не автоматический** — отдельно с налоговым консультантом (не используйте шаблоны «Form 8802» — это US-форма).

**CFC РФ:** при контроле DOO и резидентстве РФ прибыль может попадать под КИК — отдельный риск для «оставить DOO и жить в РФ».

## 4. ПМЖ и гражданство

### ПМЖ (stalno nastanjenje)

| Параметр | Детали |
|----------|--------|
| Срок | После **3 лет** непрерывного temporary residence / Unified Permit ([MUP](https://www.mup.gov.rs/), [Welcome to Serbia](https://welcometoserbia.gov.rs/permanent-residence)) |
| Непрерывность | Суммарно не более **10 месяцев** отсутствия за 3 года; не более **6 месяцев** подряд |
| Работа | Полное право без отдельного разрешения |
| Подача | Не раньше чем за **60 дней** до выполнения 3-летнего условия; пока действует текущий ВНЖ |
| Учёба | При смене основания со study — часто засчитывается **половина** времени учёбы |

**Исправление устаревшего:** до реформы 2023 требовалось **5 лет**. Сейчас стандарт — **3 года**.

### Гражданство

| Параметр | Детали |
|----------|--------|
| Обычный трек | ~**3 года** на ПМЖ + зарегистрированное место жительства |
| Отказ от гражданства | В принципе требуется; если отказ невозможен/затянут — иногда достаточно декларации о намерении (практика + адвокат) |
| Dual citizenship | Со стороны Сербии обычно **допускается**; РФ требует уведомление о втором гражданстве |
| Язык | Нет единого «сертификатного» экзамена как CIPLE, но интервью часто на **сербском** |
| Horizon | ~**6–7 лет** от первого ВНЖ до паспорта (3+3 + processing) |

Быстрые треки без обычного резидентства: происхождение, Serbian origin (ст. 23), эмигранты/потомки (ст. 18) — только при реальных основаниях, не «купить».

## 5. Банки и финансы

| Банк | Особенности |
|------|-------------|
| **AIK Banka** | Часто лояльнее к нерезидентам, online banking |
| **UniCredit Bank Serbia** | Международная сеть, SWIFT EUR/USD |
| **Raiffeisen** | Стабильный; комплаенс жёстче |
| **OTP Bank** | Нужен proof of address |
| **Intesa Sanpaolo** | Чаще corporate |

**Документы:** паспорт + White Card; для бизнеса — PIB; source of funds (договоры, выписки); иногда ВНЖ.

## 7. Консульская логистика: EU из Белграда

Сербия удобна как хаб подготовки, но **не все** национальные визы принимают из Белграда.

| Страна | Подача из Белграда | Комментарий |
|--------|-------------------|-------------|
| Германия | ✅ Часто да | National D, Blue Card — VFS / консульство |
| Испания | ✅ Часто да | DNV / non-lucrative — BLS; юрисдикция case-by-case |
| Франция | ✅ Часто да | Talent / visiteur |
| Нидерланды | ✅ Часто да | MVV + residence |
| Польша | ✅ Часто да | Work / Blue Card |
| Чехия | ✅ Часто да | Employee card / Blue Card |
| Греция | ✅ Часто да | DN / FIP — проверяйте канал |
| Португалия | ⚠️ Часто **нет** для D7/D8 | Обычно другая юрисдикция (гражданство / резиденция); не стройте план «подам D7 в Белграде» без проверки |

**Правило:** для national D почти всегда нужен **proof of legal stay** в Сербии (ВНЖ или устойчивая пријава + аренда). «Турист на 30 дней» — слабое основание.

Пока готовите пакет: senior IT — параллельно **[Role Radar](/ru/role-radar)** (EU / UK / remote под CV).

## 8. Риски и ограничения

### Миграционные

| Риск | Описание |
|------|----------|
| Визараны | 30 дней жёстко; повторный въезд не даёт «новый» лимит надёжно |
| White Card | Без пријавы — штрафы и блок на ВНЖ/банк |
| Substance | DOO/ИП без оборотов → отказ в продлении |
| Паспорт | Должен перекрывать срок ВНЖ с запасом |
| Геополитика | Давление ЕС на визовую политику; безвиз пока держится, но 5-летний план без backup рискован |

### Экономика и EU

| Риск | Описание |
|------|----------|
| Не-EU / не-Шенген | Сербский ВНЖ **не** даёт работу в EU |
| EES | Биометрический учёт пересечений Шенгена (полный rollout 2026) — 90/180 жёстче |
| ETIAS | Когда заработает для visa-exempt — отдельная pre-travel authorization для сербских паспортов |
| Динар / инфляция | Курс к EUR относительно стабилен; инфляция несколько %/год |
| Аренда | Перегрев Белграда |

### Налоговые ловушки

- Резидентство РФ не «сбрасывается» переездом само собой  
- CFC при DOO + резидентство РФ  
- IP Box только при qualifying IP и substance — не «все IT платят 3%»

## 10. Пошаговые сценарии

### A. Быстрый транзит (3–6 мес.)

Цель: EU-виза, без долгой легализации в RS.

1. Месяц 1: въезд, аренда, White Card, банк, консультация  
2. Месяц 2–3: пакет под Blue Card / D8 / DNV  
3. Месяц 4: подача national D (где юрисдикция позволяет)  
4. Месяц 5–6: переезд в EU  

Бюджет ориентир: **€3 000–5 000** за полгода (без EU-госпошлин).

### B. Легализация через DOO / ИП (3+ года)

1. Месяц 1: DOO или ИП + пријава + банк  
2. Месяц 2–4: ВНЖ (часто 6–12 мес. первая карточка)  
3. Год 1–3: substance, налоги, продления  
4. Год 3: подача на **ПМЖ**  
5. Год 4–6+: ПМЖ → опционально гражданство  

Бюджет первого года ориентир: **€8 000–12 000** (жильё + юрист/бухгалтер + налоги/взносы).

## 11. FAQ

**Нужна ли виза гражданам РФ?**  
Нет. Безвиз **30 дней**. 90 дней — только при отдельном основании. Сверяйте MUP перед билетом.

**Можно ли жить на визаранах каждые 30 дней?**  
Формально — нет надёжной схемы. Выезд не обнуляет счётчик; риск отказа на границе растёт.

**Сколько стоит DOO?**  
Госпошлины небольшие; с нотариусом, переводами и юристом — часто **€500–4 000** в зависимости от пакета.

**Нужен ли сербский для ВНЖ?**  
Для temporary residence — нет формального экзамена. Для гражданства — интервью на сербском.

**Может ли DOO работать только с иностранными клиентами?**  
Да. Для части льгот (в т.ч. экспорт / IP Box) это даже типично.

**Какие налоги у фрилансера с доходом €3 000/мес?**  
- **ИП-паушал** (если в лимите): фикс по решению ПУРС — часто **~200–250 €/мес**, не €300 как «10% от 3000»  
- **DOO:** CIT 15% от прибыли (+ зарплата директора / взносы / дивиденды)  
- С **IP Box** на qualifying IP: CIT effective ≈ 3% на эту часть дохода  

**Работают ли карты российских банков?**  
Часто нет. Нужен местный счёт. «Мир» — ограниченно.

**Недвижимость = ВНЖ?**  
Может быть основанием, но **без** фиксированного порога и без гарантии. Только жилая; MUP case-by-case.

**Гражданство через 3 года?**  
Нет. **3 года → ПМЖ**, ещё **~3 года →** право подать на гражданство. Итого ~6–7 лет.

**Можно ли подать D7 Португалии из Белграда?**  
Обычно **нет** для third-country nationals без подходящей юрисдикции. Планируйте страну гражданства/резиденции; проверяйте консульство PT.

**Сербский ВНЖ открывает Шенген?**  
Нет. Нужна отдельная виза / другие основания.

## 12. Типичные ошибки

1. Считать безвиз **90 дней**  
2. Не делать пријаву в первые дни  
3. Снимать жильё без договора  
4. Открыть «пустой» DOO без substance  
5. Путать паушал с «10% оборота» и пробить лимит 6 млн RSD  
6. Строить EU-план на подаче D7/D8 из Белграда без проверки юрисдикции  
7. Считать сербский ВНЖ «почти Шенген»  
8. Игнорировать CFC / налоговое резидентство РФ

## Коротко для проверки маршрута

- Безвиз РФ — **30 дней**, не 90; визараны ненадёжны.  
- ВНЖ: DOO / ИП-паушал / Unified Permit / недвижимость / семья; закон до **3 лет**, практика по бизнесу часто **6–12 мес.** первая карточка.  
- Паушал: **фикс** ПУРС, лимит **6 млн RSD**; НДС с **8 млн RSD** — не «10% оборота».  
- DOO: CIT **15%**; IP Box ≈ **3%** на qualifying IP.  
- ПМЖ — **3 года** непрерывного ВНЖ (не 5); гражданство — ещё ~3 года.  
- СИДН с РФ **есть**.  
- Белград: минимум ~**€1 000–1 500**, комфорт выше.  
- PT D7/D8 из Белграда — часто **нельзя**; DE/ES/FR и др. — чаще да при legal stay.
