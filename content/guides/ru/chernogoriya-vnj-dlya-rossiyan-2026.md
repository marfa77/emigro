## Прямой ответ

Черногория закрывает «эпоху безвиза» для части русскоязычных. С **1 ноября 2026** граждане **России и Беларуси** теряют безвизовый въезд. **Украинцы** сохраняют **90/180**; у **казахстанцев** — сезонное окно до **01.10.2026**. Digital Nomad — единый маршрут, но sunset **31.12.2026** и практический дедлайн **октябрь 2026**. DOO и недвижимость с **17.01.2026** дороже для всех non-EU.

> **Дисклеймер.** Не юридическая, налоговая или военная консультация. Визы, пороги DOO/RE и практика MUP меняются — сверяйте gov.me / digitalnomads.gov.me / mup.gov.me и лицензированного юриста в Черногории.

## 2. Въезд: четыре сценария

### Россия: безвиз до 31.10.2026

До **31.10.2026** — безвиз до **30 дней**. Визараны в RS/BA после 3–4 кругов — вопросы на границе. С **01.11.2026** — **виза** через VFS (Москва, Дубай, Стамбул, Баку, Дели…). e-Visa анонсировали без даты запуска.

**Практика:** въезжайте до конца октября или оформляйте визу заранее. Для nomad/DOO нужен легальный въезд — с 1 ноября без визы не зайдёте.

### Беларусь: как у России

Те же 30 дней до **31.10**, виза с **01.11**. VFS для BY планируют позже; на старте — третьи страны / VFS RU–TR–AE.

### Украина: безвиз сохраняется

**90 дней в любые 180** — **не** меняется с 01.11 (UA не в пятёрке ужесточения). Регистрация по прибытии — **24 часа** (отель или турфирма при аренде); штраф от **€60**.

### Казахстан: сезонное окно

Безвиз **01.05–01.10.2026** (30 дней). Вне сезона и после 01.10 — сверяйте. Не в списке виз с 01.11, но сезонное освобождение кончается раньше.

## 3. Digital Nomad — единый маршрут

Условия **одинаковы** для RU/UA/KZ/BY. Программа с 2022; **sunset 31.12.2026**. Подачи после — могут закрыть; практический дедлайн **октябрь 2026** (рассмотрение 1–2 мес.). Permit, выданный до sunset, действует полный срок.

| Параметр | Требование |
|----------|------------|
| Доход | ≥ **3×** мин. зарплата ≈ **€1 800**/мес (без высшего) или **€2 400**/мес (bachelor's+) |
| Работа | Remote для foreign employer / своего бизнеса **вне** ЧГ |
| Налог на foreign income | **0%** при статусе nomad |
| Срок | до **2** лет + одно продление (**макс. 4**), затем 6 мес. вне страны |
| ПМЖ / гражданство | **Нет** прямого пути |
| Семья | супруг/а и дети |

**Документы:** паспорт, proof of remote work, bank statements, страховка от **€30 000**, аренда, несудимость с апостилем, фото.  
**Подача:** лично в **MUP** после въезда; ~**€67** + **€25** за карту. [digitalnomads.gov.me](https://digitalnomads.gov.me/).

**Критично:** регистрация **DOO / local business отменяет** nomad. Один маршрут.

### Таймлайн nomad

| Неделя | Действие |
|--------|----------|
| 1 | Въезд (см. паспорт), аренда, proof of remote |
| 2 | Выписки, страховка, criminal record + апостиль |
| 3 | Подача MUP, ~€67 |
| 4–8 | Рассмотрение, биометрия, карта ~€25 |
| 24 мес. | Renewal (одно; макс. 4 года) |

## 4. DOO: ужесточение с 17.01.2026

Процедура **одинакова** для всех non-EU (все четыре группы).

| Параметр | До 17.01.2026 | После 17.01.2026 |
|----------|---------------|------------------|
| Соцвзносы директора | минимальные / номинальные | мин. **~€5 000/год** (~€416/мес) при non-EU владельце >51% |
| Setup | €500–1 500 | setup тот же; годовой cash-out вырос |
| Исключение | — | граждане EU/ЕЭЗ/CH и семьи |

DOO больше не «дешёвый backup» после закрытия nomad. Годовой бюджет маршрута ориентир **€15 000–20 000+** (аренда, соцвзносы, бух, сборы).

**Налоги DOO:** CIT **9%**; уставной капитал символический (€1); бухгалтер Подгорица **€100–300**/мес.

### Таймлайн DOO + ВНЖ

| Неделя | Действие |
|--------|----------|
| 1–2 | Юрист, name, регистрация CRPS, налоговый номер |
| 3–4 | Счёт компании, аренда (личная + адрес) |
| 5 | Несудимость (апостиль + перевод) |
| 6–8 | MUP, биометрия |
| 10–12 | Residence card |

## 5. Недвижимость: €150 000 и закрытый CBI

**CBI закрыта** — покупка ≠ гражданство.

С **17.01.2026** для **всех non-EU**:

| Параметр | Требование |
|----------|------------|
| Минимум | **€150 000** **tax-assessed** value (не цена в договоре) |
| Суммирование | несколько объектов до порога |
| Срок ВНЖ | 1 год + продление при ownership |
| EU/EEA/CH | освобождены от порога |

**Ловушки:** off-plan рискован для visa; tax value часто **ниже** рынка; до сделки — **письменное** подтверждение immigration lawyer.

**Рынок 2026:** Будва/Бечичи €1 500–3 000/м²; Тиват (Porto Montenegro) €3 000–6 000/м²; Подгорица €1 000–2 000/м²; Котор €1 500–2 500/м².

## 6. Стоимость жизни, банки, налоги

### Бюджет (2026)

| Город | Одному | Семья |
|-------|--------|-------|
| Будва / Бечичи | 900–1 600 € | 1 800–3 000 € |
| Котор | 850–1 400 € | 1 700–2 800 € |
| Подгорица | 700–1 200 € | 1 400–2 400 € |
| Тиват | 950–1 700 € | 1 900–3 200 € |

Валюта — **евро**. Лето +30–40% к аренде; годовой контракт с октября — экономия. Зимой на побережье сервисы редеют — для документов удобнее Подгорица.

### Банки

| Банк | Профиль |
|------|---------|
| CKB | универсальный; счёт часто с residence |
| Erste | corporate + retail; case by case |
| Hipotekarna | ипотека, SME |
| Lovćen | локальный; проще для новоприбывших |

SWIFT работает. RU/BY — enhanced due diligence; UA/KZ обычно проще. Карты РФ под санкциями **не работают**.

### Налоги

PIT прогрессивный до **15%**; CIT DOO **9%**; резидентство при **183+** днях — отдельная консультация.

## 7. Военный учёт: четыре паспорта

Не юридическая консультация по уклонению — только миграционный контекст.

| Паспорт | Ориентир |
|---------|----------|
| **РФ** | Высокий риск. Публичных кейсов принудительной выдачи по воинскому учёту в ЧГ нет, но статусы меняются. При риске — адвокат по международному праву. |
| **UA** | Мужчины **18–60**: консульство ведёт учёт; границы третьих стран — проверяйте требования на выезд. |
| **KZ** | Низкий: мобилизация граждан KZ не проводится; учёт в ЧГ не актуален. |
| **BY** | Средний: официальной мобилизации нет; для политического бэкграунда — правозащитные организации. |

## 8. Путь в ЕС

Черногория — **не EU и не Шенген**. Для ЕС — отдельная виза.

| Консульство в Подгорице | Статус |
|-------------------------|--------|
| IT / DE / FR | ✅ |
| ES / GR | ограничено |
| PT | ❌ |

Часто удобнее **Белград** или **Тирана**. Черногорский ВНЖ усиливает proof of residence — не гарантия D7 / Elective Residence.

**Стратегия:** месяцы 1–3 — въезд, аренда, счёт → 3–6 — nomad (до октября) или DOO → 6–12 — история residence/выписки → 12+ — пакет EU из подходящей юрисдикции ([wizard](/ru/wizard)).

## 9. Риски и типичные ошибки

1. Sunset nomad **31.12.2026** — дедлайн подачи **октябрь**.  
2. DOO с 17.01 — мин. **~€5 000**/год соцвзносов non-EU.  
3. Недвижимость ≠ ВНЖ без tax value ≥€150 000 + lawyer OK.  
4. Не EU — Шенген отдельно.  
5. CBI закрыта; натурализация **10+** лет.  
6. Сезонность побережья.

| Ошибка | Кто | Почему |
|--------|-----|--------|
| Ждать «до ноября» без визы | РФ/BY | С 01.11 виза; VFS — недели |
| DOO + nomad одновременно | Все | Local business отменяет nomad |
| Квартира «под визу» без tax value | Все | Оценка <€150k → нет ВНЖ |
| «DOO за €1 500» | Все | Это setup; год €15k+ |
| Игнор регистрации 24ч | Все | штраф €60+, проблемы с продлением |

## 10. FAQ по группам

### Россия

**Виза с 01.11.2026?** Да, VFS / посольства — заранее.  
**Мир?** Нет — местный счёт после регистрации/ВНЖ.  
**Nomad после 01.11?** Только при легальном въезде по визе; сам статус не отменяется, безвиз — да.

### Украина

**Безвиз после 01.11?** Да, 90/180.  
**Work permit для DOO?** Директор своей компании — residence через MUP по общим non-EU правилам.  
**Мобилизация?** Мужчины 18–60 — украинский военный юрист; консульство ведёт учёт.

### Казахстан

**Безвиз после 01.10?** Сезон кончается; сверяйте. Не в пятёрке виз с 01.11.  
**SWIFT из KZ?** Обычно стабильнее, чем из РФ.  
**KAZTEST для ЧГ?** Нет — это требование РК.

### Беларусь

**Виза с 01.11?** Да, как РФ.  
**Белкарт / Мир?** Не рассчитывать; Visa/MC BY — case by case → местный счёт.

## 11. Чек-лист: первые 90 дней

### До вылета

- [ ] Визовый режим по паспорту (раздел 2)
- [ ] Страховка ≥€30 000
- [ ] Выездной билет / proof of funds (~€50/день)

### Неделя 1

- [ ] Регистрация ≤24 ч
- [ ] Аренда (договор для ВНЖ)
- [ ] Счёт CKB/Erste (residence или address)
- [ ] SIM (Telenor / m:tel / One)

### Недели 2–4

- [ ] **Nomad:** remote proof, выписки, criminal record + апостиль — подача до **октября 2026**
- [ ] **DOO:** юрист, CRPS, понимать €5k+/год
- [ ] **RE:** tax value + immigration lawyer до сделки

### Месяцы 2–4

- [ ] Подача MUP, сборы ~€67 + €25
- [ ] Ожидание 1–2 мес. → residence card
- [ ] Параллельно — EU-пакет (выписки, налоги)
