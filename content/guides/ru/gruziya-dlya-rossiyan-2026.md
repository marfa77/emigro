## Прямой ответ

Грузия 2026 — не «открытые двери» 2022-го. **Медстраховка на въезд**, **work permit с 1 марта**, порог ВНЖ через недвижимость **$150 000** и отдельный **IT Residence Permit** — новая нормаль. Безвиз **365 дней**, банки TBC/BOG и Virtual Zone остаются, но схема «живу на безвизу и ничего не оформляю», если зарабатываете из Грузии, стала рискованной.

## 1. Въезд: страховка, безвиз, граница

### Медстраховка (с 1 января 2026)

Покрытие **не менее 30 000 лари** (≈$11 000) на **весь** период пребывания.

| Риск | Последствие |
|------|-------------|
| Нет полиса / слабое покрытие | Отказ во въезде и/или штраф ~**300 лари** |
| Полис короче поездки | Формально недостаточен |

Оформляйте **до** билетов; PDF + распечатка. Подходят международные/российские туристические полисы при совпадении суммы и дат.

### Безвиз РФ

До **365 дней подряд** без визы. После исчерпания — выезд (повторный въезд обычно **начинает новый** отсчёт) или ВНЖ. Это не «автопродление на месте».

### Отказы на границе

Официального запрета по возрасту/призыву **нет** — решение **дискреционное**.

Повышенное внимание (не гарантия отказа): место рождения (Крым, новые регионы, Абхазия/Южная Осетия), нет жилья/средств/цели, силовые связи / символика, многократные border run, мужчины 18–35 — чаще детальный опрос.

**На границу:** страховка, бронь, выездной билет, средства (~€2–3k), понятная цель.

## 2. Работа с 1 марта 2026

Постановление Правительства №70: для иностранцев без ПМЖ — **Right to Labour Activity / work permit**. Штраф без разрешения — ориентир **~2 000 лари**. Уже работавшим до реформы иногда дают переходный горизонт (встречается ориентир до **01.01.2027**) — **новые** кейсы считайте сразу по новым правилам.

### Кто часто освобождён от work permit

| Категория | Статус |
|-----------|--------|
| ПМЖ / постоянный статус | Обычно освобождены |
| Investment residence **$300k+** | Обычно освобождены |
| Дипломаты / спецкатегории | По правилам |
| Остальные | Work permit нужен |

### «Удалёнка только на иностранцев»

Чаты обещают исключение. Emigro: **не надёжная позиция**.

- Миграционная трактовка после 1.03.2026 неоднозначна; юрфирмы часто советуют оформлять статус при физическом присутствии.
- Чёткого официального «всегда без permit при 100% foreign clients» нет.

| Сценарий | Практика Emigro |
|----------|-----------------|
| Только foreign clients, stay долго | Не полагаться на исключение → **IT Residence** (если IT) или work permit / трудовой ВНЖ |
| Грузинский работодатель / local clients | Work permit + основание пребывания |
| Инвест ≥$300k | Work permit обычно не нужен |
| Найм в GE-компанию | Worknet **10 рабочих дней** → permit → ВНЖ |

## 3. Шесть маршрутов ВНЖ

### 1) IT Residence Permit (с сент. 2025) — главный для IT/удалёнки

| Параметр | Ориентир |
|----------|----------|
| Первый срок | **3 года** |
| Продления | Ещё по 3 года, суммарно до **~12 лет** |
| Доход | ≥**$25 000**/год за 12 мес. (≥2 платежа, интервал ≥30 дней) |
| Опыт IT | ≥**2 года** |
| Семья | По правилам программы |
| Срок рассмотрения | Часто **60–100+ дней** |

### 2) Трудоустройство + labor market test

1. Вакансия на **Worknet** ≥**10 рабочих дней**  
2. Нет подходящего местного кандидата  
3. Work permit  
4. ВНЖ (часто 6–12 мес. + продление)  

Исключения из теста (высокая зарплата, International Company и др.) — через юриста работодателя.

### 3) Недвижимость ≥ **$150 000** (с 1.03.2026)

| Период | Порог |
|--------|-------|
| До 1.03.2026 | $100 000 |
| С 1.03.2026 | **$150 000** рыночной оценки |

Оценщик аккредитованный; цена в договоре ≠ автоматически оценка. Несколько объектов можно суммировать. Старые сделки с регистрацией до 1.03 — отдельные правила продления; **новые** — только новый порог. Short-term residence обычно **1 год** при сохранении ownership.

### 4) Investment ≥ **$300 000**

Срок ориентир **5 лет**; ключевой плюс — часто **освобождение от work permit**. Недвижимость и/или капитал в GE-компанию — по актуальной инструкции.

### 5) ИП / компания

Регистрация без мин. капитала возможна. **Пустой ИП ≠ ВНЖ**. Нужна деятельность; для self-employed часто отдельный permit. IT с ≥$25k — логичнее сразу **IT Residence**.

### 6) Семья

Супруг/дети с гражданством или ВНЖ GE — через агентство госуслуг по правилам воссоединения.

## 4. IT Residence: зачем и какие документы

**Кому:** разработчики, DevOps, QA, data, PM, UX, фриланс с foreign contracts, сотрудники GE IT, IT-фаундеры.

**Пакет (ориентир):** паспорт + перевод; доход ≥$25k; опыт 2+ года; страховка; аренда/собственность; фото; пошлина.

| | IT Residence | Недвижимость $150k | Найм |
|--|--------------|-------------------|------|
| Срок | 3 года | ~1 год | 6–12 мес |
| Work permit | Обычно не нужен отдельно | Обычно не нужен | Нужен |
| Worknet | Нет | — | 10 дней |
| Ресурс | Доход $25k/год | Капитал $150k | Зарплата |
| Привязка | К статусу IT | К ownership | К работодателю |

## 5. Недвижимость: ловушки

| Миф | Реальность |
|-----|------------|
| «Куплю за $100k по-старому» | При регистрации после 1.03.2026 — **$150k** |
| «Цена в договоре = порог» | Нужна **рыночная** оценка |
| «Несколько мелких квартир» | Можно суммировать до ≥$150k |
| «Это сразу ПМЖ» | Обычно short-term + продления |
| «Куплю и сдам» | Аренда облагается; самостоятельное управление может тянуть work permit |

**Рынок (ориентир):** Тбилиси центр $1 500–2 500/м²; спальные $800–1 300; Батуми центр/море $1 200–2 000.

## 6. Налоги: 183 дня, Virtual Zone, СИДН

**≥183 дня** в календарном году → налоговый резидент GE (мировые доходы по правилам GE).

| Доход | Ориентир ставки |
|-------|-----------------|
| Зарплата / ИП | **20%** |
| Дивиденды / проценты | **5%** |
| Cap gains | **5–20%** |

**Virtual Zone:** 0% на прибыль от **иностранных** клиентов для **компании** с сертификатом, substance и IT-кодами — **не** замена IT Residence для физлица.

**СИДН РФ–Грузия: не действует** (не ратифицирован). Риск двойного налогообложения — считайте **обе** юрисдикции; переезд не снимает автоматически обязательства в РФ.

---

## 7. Банки

**TBC / BOG:** паспорт, регистрация адреса (Дом юстиции), ИНН; комплаенс для РФ усилен; SWIFT USD/EUR возможен с EDD на крупных суммах.

**Credo / Liberty** — проще розница, слабее SWIFT. **ProCredit** — строже.

Карты санкционных РФ-банков не работают. Наличные крупные суммы — декларация на границе.

## 9. Риски и путь в ЕС

- Закон об «иностранном влиянии» (2024) бьёт по НКО/климату, не по каждому экспату напрямую — но неопределённость реальна.  
- Бытовые трения возможны; системной «охоты» нет.  
- Медицина: въездной полис ≠ год жизни; расширенный ~**50–150 €**/мес.  
- Консульства в Тбилиси ≠ авто-приём D7/D8 с одного безвиза. С **грузинским ВНЖ** шансы на юрисдикцию выше, но не гарантия — сверяйте сайт консульства.

| Реалистично | Часто нет |
|-------------|-----------|
| Пакет, апостили, банковская история | D7/D8/GV без GE-статуса / иной юрисдикции |
| Подача из страны резидентства | «365 дней безвиза» как достаточное основание |

## 11. FAQ

**Нужна ли медстраховка?**  
Да, с 1.01.2026, ≥30 000 лари на весь срок.

**Порог недвижимости?**  
**$150 000** рыночной оценки с 1.03.2026 для новых сделок.

**IT Residence?**  
3 года, ≥$25k/год, ≥2 лет опыта, продления до ~12 лет.

**Можно ли работать на безвизу без permit?**  
Local-source — нет (штраф ~2k лари). «Только иностранцы» — серая зона. Инвест $300k+ — обычно без work permit.

**Labor market test?**  
Worknet ≥10 рабочих дней до permit.

**СИДН с РФ?**  
Нет.

**D7 из Тбилиси с безвиза?**  
Скорее нет без GE ВНЖ / иной юрисдикции.

**Карты банков РФ?**  
Санкционные — нет. Открывайте TBC/BOG.

### Грузия vs Армения (кратко)

| | Грузия | Армения |
|--|--------|---------|
| Безвиз | 365 дней подряд | 180 дней суммарно/год |
| Work permit | С 1.03.2026 широко нужен | ЕАЭС — без permit на найм |
| IT-налоги физлица | ~20% (VZ — для компании) | ИП IT **1%** оборота |
| СИДН с РФ | Нет | Есть |
| Бюджет | Часто дороже | Часто дешевле |

## 12. Типичные ошибки

1. Въезд без страховки ≥30k лари.  
2. Жить на «foreign clients = без permit».  
3. Покупать под ВНЖ за $100k после 1.03.2026.  
4. Путать Virtual Zone с IT Residence.  
5. Считать, что СИДН с РФ защищает.  
6. Подавать PT D7 с одного безвиза в Тбилиси.  
7. Пустой ИП «ради статуса».
