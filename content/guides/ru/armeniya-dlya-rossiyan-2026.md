## 2. Безвиз и лимит 180 дней

### Общее для RU / UA / KZ / BY

Безвиз до **180 дней суммарно** за скользящий **12-месячный** период (на практике также смотрят календарный год). Это **не** 180 дней на каждый визит.

**Ключевое:** выезд и повторный въезд **не обнуляют** счётчик. «Визаран в Грузию на выходные» формально **не** даёт новый лимит — погранслужба ведёт накопительный учёт.

**Превышение:** ориентир штрафа ~**50 000 драм (~130 USD)** при выезде, риск запрета на въезд; нарушение остаётся в базе.

### Паспорта и документы

| Страна | Внутренний паспорт | Загран | Наземная граница |
|--------|--------------------|--------|------------------|
| Россия | Да, только прямые авиарейсы | Да | Только загран (Грузия, Иран) |
| Украина | Нет | Да | Только загран |
| Казахстан | Нет | Да | Только загран |
| Беларусь | Да, только прямые авиарейсы | Да | Только загран |

Для **ВНЖ, банков и госорганов** нужен **загранпаспорт**. Внутренний РФ/BY — только авиа-въезд и короткое пребывание.

### Регистрация по адресу

После ВНЖ регистрация по адресу обычно **обязательна** (ориентир — в течение **15 дней** по закону об иностранцах). Без ВНЖ/основания бесконечно жить нельзя. «Серые» схемы с периодическими выездами без регистрации — нарушение, не план Emigro.

## 3. ВНЖ: ЕАЭС vs не-ЕАЭС

### ЕАЭС: Россия, Казахстан, Беларусь

Отдельное **разрешение на работу** для найма **не требуется** — трудоустройство на условиях, близких к местным.

**Рабочие пути ВНЖ:**

- Трудовой договор с армянским работодателем — часто на срок договора, до 1 года с продлением.
- **ИП** → налоговый учёт → отдельная подача на ВНЖ.
- Семья (брак / дети-граждане Армении).

**Пакет (ориентир):** паспорт + перевод на армянский; договор или свидетельство ИП; аренда; несудимость (апостиль + перевод); страховка / медсправка; пошлина.

**Сроки:** официально часто 10–20 рабочих дней; на практике в 2025–2026 — **30–60 дней** и дольше.

### Не-ЕАЭС: Украина

Для найма нужен **work permit**, затем ВНЖ. Сроки длиннее, чем у ЕАЭС. Исключения (ВКС и спецрежимы) — штучные.

**Рабочие пути для UA:**

- Work permit + трудовой договор (подаёт работодатель).
- **ИП → ВНЖ** — основной путь для фриланса/удалёнки (регистрация ИП доступна без ЕАЭС).
- Семья; учёба → студенческий ВНЖ.

Армянский ВНЖ **не даёт** автоматический доступ к рынку труда РФ/KZ/BY: для работы там — отдельные правила тех стран.

**Важно:** открыть ИП ≠ автоматически получить ВНЖ. Нужна отдельная подача с подтверждением деятельности и адреса.

## 4. ИП и налоги: 1% IT для всех

### Оборотный налог

ИП с оборотом до ~**115 млн драм/год** (~$290k) может быть на **оборотном налоге** (не с прибыли):

| Вид деятельности | Ставка (ориентир) |
|------------------|-------------------|
| IT из госсписка high-tech | **1%** |
| Производство | ~7% |
| Торговля / услуги | ~10% |
| Общий режим (компании) | ~18% с прибыли + НДС |

### Фиксированные платежи (не «% от оборота»)

| Платёж | Ориентир |
|--------|----------|
| Соцвзнос | ~5 000 драм/мес |
| Фикс. налог на доход | ~5 000 драм/мес |
| Stamp / военный сбор | 12 000–120 000 драм/год (от оборота) |
| Медстраховка | ~130 000 драм/год |

При обороте ~$100k/год типичная картина: **1% оборота + фиксированный пакет**, а не миф «+5% соцвзносов от оборота».

### Отчётность и регистрация

- Квартальные декларации по оборотному налогу; упрощённый учёт.
- Оборот выше ~115 млн драм → общий режим / НДС 20%.
- На практике нужен бухгалтер.

**Шаги ИП (одинаково для четырёх паспортов):** налоговая / e-gov → заявление Անհատ ձեռնարկատեր → соцномер → код IT для 1% → выбор оборотного режима в сроки SRC. Через агента часто **$50–150**, **1–2 дня**.

**Налоговое резидентство:** **180 дней** миграционного безвиза ≠ автоматически **183 дня** налогового резидентства. Стройте статус осознанно, особенно при доходах из нескольких стран.

## 5. Банки: четыре сценария

### Россия

- Ameriabank, Inecobank, Evocabank, IDBank — часто открывают при ВНЖ / долгом основании.
- **Мир:** снятие в основном в банкоматах **ВТБ (Армения)** с комиссией ~**1%** (лимиты по операции). С марта 2024 ВТБ — один из немногих банков AM с полноценным Мир; в других POS/ATM карты РФ обычно не работают.
- **SWIFT из РФ:** тяжело, посредники / валютный контроль; исходящие возможны, но дорого и медленно.
- Не опирайтесь на российские карты как на основной канал.

### Украина

- SWIFT из UA возможен при правилах **НБУ**; крупные суммы требуют подтверждений.
- Visa/Mastercard UA работают в ATM AM с комиссиями эмитента + ATM; банк иногда блокирует «подозрительные» страны — предупреждайте о поездке.
- Для ИП и налогов лучше армянский счёт (перевод / наличные USD·EUR).

### Казахстан

- Visa/Mastercard KZ обычно без особых проблем; корреспонденция с AM проще, чем из РФ.
- SWIFT без «российского» санкционного слоя.
- На старте можно жить на KZ-счёте; для ИП/налогов — местный счёт.

### Беларусь

- Часть банков AM делает **enhanced due diligence** по BY.
- Белкарт / Мир BY practically не работают; нужны Visa/Mastercard.
- SWIFT возможен с запросами документов. Открывайте местный счёт сразу для долгого stay.

## 6. Военный учёт: контекст по странам

Это **не** инструкция по уклонению от учёта — только миграционный контекст хаба.

### Россия

Армения не проводит мобилизацию граждан РФ и не является «страной выдачи российских повесток» в бытовом смысле. Публичных массовых кейсов принудительного возврата «по воинскому учёту» через армянские органы не описано как стандарт.

Нельзя обещать «безопасную гавань в правовом смысле»: при ВНЖ данные попадают в местные системы; взаимодействие ведомств меняется. При личном риске — адвокат по международному праву, не чат.

### Украина

Мужчины 18–60 в зоне мобилизационного учёта. Армения не выдаёт украинские повестки, но консульство UA может вести учёт граждан за рубежом; пересечение третьих стран для мужчин 18–60 часто чувствительно к документам на выезд. Консультируйтесь с украинским юристом по военному праву **до** долгого stay.

### Казахстан

Мобилизация граждан KZ не проводится; военный учёт в AM для казахстанцев обычно не драйвер выбора хаба.

### Беларусь

Официальной мобилизации граждан BY нет. Риски давления на диаспору / родственников в РБ индивидуальны и ниже «массового» нарратива по РФ, но для политически чувствительных кейсов — правозащитные консультации.

Армянский ВНЖ **не открывает** Шенген, но даёт адрес, выписки и налоговую историю.

## 9. Риски и ограничения

- **Зависимость от РФ** в экономике и притоке релокантов → аренда и цены.
- **ОДКБ:** после 2023 Армения усилила партнёрства с ЕС/США; участие в ряде мероприятий ОДКБ **заморожено**. Формулировка «вышла из ОДКБ» слишком сильная: полная денонсация членства на август 2026 не равна этому тезису.
- **Границы:** с Турцией и Азербайджаном закрыты; с Грузией открыта, нужен загран. Авиа EVN → EU есть, но хаб слабее Белграда по цене/частоте.
- **Санкции:** RU/BY — ограниченный SWIFT и узкий Мир; UA — контроль НБУ; KZ — минимум ограничений.
- **Инвесторский ВНЖ «за квартиру»:** покупка недвижимости **сама по себе не равна** ВНЖ. Не планируйте по мифу «$100k = статус». Любые future fast-track — только после публикации порогов.

## 10. Пошаговые сценарии

### РФ, удалёнка / IT

1. Въезд (авиа: возможен внутренний паспорт) → загран для банка/ВНЖ.  
2. Счёт Ameria/Ineco; не опираться на Мир вне ВТБ.  
3. ИП 1% IT → квартальная отчётность.  
4. Подача на ВНЖ (30–60 дней на практике).  
5. Параллельно EU-пакет; PT D7/D8 — **не** из Еревана.

### UA, фриланс

1. Только загран.  
2. ИП (без ЕАЭС) → ВНЖ; найм — только с work permit.  
3. SWIFT с учётом НБУ; местный счёт.  
4. Мужчины 18–60 — юрист по военному учёту до долгого stay.

### KZ / BY, ЕАЭС

1. Загран (KZ всегда; BY — авиа может быть на внутренний).  
2. Найм без work permit или ИП → ВНЖ.  
3. BY: сразу местный счёт (EDD). KZ: можно стартовать на Halyk/Kaspi card, но для налогов — AM-счёт.

## 11. FAQ

**Сколько можно без ВНЖ?**

До **180 дней суммарно**/год для всех четырёх. Выезд не обнуляет.

**Нужен ли загран?**

UA/KZ — всегда. РФ/BY — для авиа иногда внутренний; для ВНЖ, банков и суши — загран.

**Какая ставка IT-ИП?**

**1% оборота** + фиксированные платежи. Не «6%» и не «+5% соцвзносов от оборота».

**Можно ли подать PT D7 из Еревана?**

**Нет.** Обычно Тбилиси, Стамбул или Москва.

**UA: нужен work permit?**

Для найма — да. Для ИП и учёбы — другие основания.

**KZ: можно работать на казахстанскую компанию из AM?**

Да как модель дохода, но налоговое резидентство AM стройте осознанно; есть СИДН KZ–AM — сверяйте с налоговым консультантом.

**BY: отказывают в банке из‑за санкций?**

Чаще EDD, чем массовый отказ. Ameria/Ineco обычно рабочие варианты при полном пакете.

**180 дней = налоговое резидентство?**

Нет. Миграционный лимит и налоговые 183 дня — разные режимы.

## 12. Типичные ошибки

1. Визараны «в Грузию на 3 дня» как способ обнулить 180 дней.  
2. Путать ИП с автоматическим ВНЖ.  
3. Планировать PT D7/D8 из Еревана.  
4. Жить на картах Мир / Белкарт без местного счёта.  
5. Для UA — идти в найм без work permit.  
6. Обещать себе «безопасную гавань» по военному учёту без юриста.  
7. Покупать квартиру «ради ВНЖ» по мифу $100k.
