# Fact-check: primary official sources

Канон для будущих аудитов: **сначала primary**, потом secondary. Блоги, AmCham, PwC, Visafoto — только как подсказка; **не** источник истины, если расходятся с primary.

## Правила

1. **Primary** = гос. орган иммиграции / виз / permits (или единый gov-портал маршрута).
2. **Secondary** = налоги / fees / гражданство, если гайд это покрывает.
3. Сравнительные гайды (`digital-nomad-vizy-…`, `kuda-…`, `nalogovye-…`) — фактчек **по строкам страны** через primary той страны.
4. `pervye-30-dnej-v-*` — тот же primary, что у country pillar (+ местный соцстрах/налог при необходимости).
